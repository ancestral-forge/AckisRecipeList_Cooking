# Карта неизученных рецептов готовки

Локальное расширение **основного Ackis Recipe List Classic 11.0.2**, проверенное
с установленной базой Cooking для TBC Anniversary. Исходники хранятся здесь,
поскольку этот репозиторий содержит только базу Cooking, а не основной ARL.

Карта включается при входе персонажа с готовкой. Сканировать профессию вручную
не требуется. На карте мира и миникарте отображаются неизученные рецепты
с известными координатами источников, независимо от фильтров списка ARL:

- Мешочек — продавец; значок профессии — тренер; `!` — задание; череп — добыча с NPC.
- Обводка — наибольшая доступная сложность: оранжевая, жёлтая, зелёная, серая.
  Красная означает, что все оставшиеся рецепты требуют большего навыка или репутации.
- В подсказке — текущий навык, полный список рецептов с индивидуальными цветами,
  требуемым навыком и недостающей репутацией. Длинные списки прокручиваются колесом.
- ЛКМ ставит маршрут TomTom, если он установлен. Для самих меток TomTom не нужен.
- `/arlcookingmap off` выключает карту, `/arlcookingmap on` включает.
  Команда без аргумента переключает режим. Настройка сохраняется в профиле ARL.

Цвета пересчитываются после изменения навыка, репутации и изучения рецепта.
Будущие дополнения и источники другой фракции отсекаются. Рецепты без точного
места получения (например, случайная добыча по всей зоне) не получают выдуманную
точку. Доступность определяется навыком и репутацией; остаток товара у продавца,
цепочки заданий и фазы сервера из этой базы определить нельзя.

## Установка

Из корня репозитория:

```sh
lua local-patches/AckisRecipeList/tests/cooking-map.lua
lua local-patches/AckisRecipeList/tests/vendor-seasonal.lua
luacheck local-patches/AckisRecipeList/CookingMap.lua local-patches/AckisRecipeList/Objects/AcquireType/Vendor.lua --std lua51 --no-max-line-length
python3 local-patches/AckisRecipeList/install.py
```

Установщик добавляет `CookingMap.lua` в основной аддон, подключает его в TOC
и заменяет `Objects/AcquireType/Vendor.lua`, чтобы сезонные сноски были видны
в классическом списке источников ARL рядом со штатными подсказками вроде
ограниченного запаса. Путь к другой установленной копии ARL можно передать
первым аргументом. Исходный TOC и предыдущие версии файлов сохраняются в
`backups/`. После установки нужен `/reload` в WoW. Обновление основного ARL
менеджером аддонов может удалить расширение — тогда повторить установку.

Для удаления убрать строку `CookingMap.lua` из TOC, удалить этот файл и
вернуть штатный `Objects/AcquireType/Vendor.lua` из бэкапа или переустановить
основной ARL, затем `/reload`. База рецептов и SavedVariables не заменяются.

Локальные тесты проверяют логику и работу с имитацией WoW API. Визуальная
проверка в запущенном клиенте проводится отдельно.
