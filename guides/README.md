# Cooking Triage Verification

Полная перепроверка известных Cooking-источников Classic/TBC для Альянса,
включая уже изученные рецепты. Отдельный аддон для **Guidelime + TomTom**, TBC
Anniversary (`20506`); ARL для работы не требуется.

Каталог: **367 связок «рецепт + источник»**, **92 NPC**. Основной маршрут —
**132 шага, 88 NPC**; ещё 4 сезонных NPC находятся в `Deferred Sources`.
Проверки Thistle Tea показываются только разбойнику, поэтому число строк пробега
зависит от класса. Под «всеми» понимается объединение источников исходной базы,
исправлений и альтернатив из Cooking-аудита; это не заявление, что в игре нет
других неизвестных источников.

## Запуск и результат

1. Включи `Guidelime: Cooking Triage Verification`, `Guidelime`, `TomTom`.
   После обновления — `/reload`; после первой установки нового аддона — перезапуск WoW.
2. В `/lime` выбери **Cooking Triage → Cooking Triage Verification**.
   Начало — **Шаттрат**, все грифоны Альянса считаются открытыми.
3. `/ctriage start` начинает пробег. Каталог, ожидания и группы копируются в сохранение
   **до наблюдений**. Повторный `start` продолжает незавершённый пробег.
4. Открывай меню NPC, подожди примерно 2 секунды. Найденные item/spell ID отмечаются
   автоматически; окно `/ctriage` показывает все ожидаемые строки этого NPC.
5. Для ручных отметок добавь пояснение. **Есть** — источник непосредственно проверен;
   **Нет** — полное меню перепроверено, запас/фильтры/условия не мешают выводу;
   **Позже** — проверить нельзя; **Сброс** — вернуть строку к проверке, сохранив историю.
   Если у NPC вообще нет меню тренера, используй **NPC не тренер**: кнопка отметит
   все тренерские строки этого NPC как отсутствующие и сохранит пояснение.
6. `/ctriage report` — итоговый отчёт и подробные строки для копирования.
   `/ctriage finish`, затем `/reload` — завершить пробег и сохранить результат на диск.

В каждой строке независимо заданы **исходная уверенность** и **ожидаемое наличие**:

| Группа | Основание до обхода |
| --- | --- |
| Уверенная (`У`) | Источник согласован в исходной базе и аудите; для двух отрицательных контролей Craig есть предыдущее живое наблюдение |
| Сомнительная (`?`) | Источник добавлен/удалён, расходится между базами или был выделен в прошлом triage |

«Уверенная» не означает уже подтверждённую в этом пробеге. Для каждой группы отчёт
считает **совпало / не совпало / не проверено / отложено / конфликт**. Доля совпадений
считается только среди однозначно проверенных строк. Если ожидалось отсутствие,
проверенное отсутствие — совпадение, а найденный рецепт — расхождение.

Ни изучение рецепта, ни прибытие к точке, ни галочка Guidelime не подтверждают источник.
Один NPC может содержать обе группы и несколько разных результатов. Для квеста
ключ включает также quest ID и конкретного NPC: одинаковый предмет из другого
квеста не засчитывается.

## Как избежать ложных отрицаний

У тренеров включай **available, unavailable, used** и раскрой группы. Сканер
не меняет фильтры, ничего не покупает и не изучает. Неполные/незагруженные меню
разрешают подтвердить найденную строку, но не отсутствие остальных.

Кнопка **Нет** требует открытого полного меню именно этого источника и отдельного
подтверждения пользователя. Она недоступна при незагруженных строках, скрытых
услугах, свёрнутых группах, закрытом окне или другом NPC/квесте. Ограниченный запас,
нехватка репутации, завершённый/недоступный квест и отсутствующий NPC означают
**Позже**, а не опровержение. Видимый рецепт с остатком 0 подтверждает наличие
источника; отсутствие видимой строки само по себе ничего не доказывает.
Для NPC без тренерского окна отдельная кнопка **NPC не тренер** является явным
ручным подтверждением отсутствия меню и отмечает все его тренерские строки.

В списке рецептов **Limited** означает ограниченный запас, замеченный автосканом;
пометка сохраняется после покупки и `/reload`. У шести рецептов Vendor-Tron 1000
сразу показано **Limited: 1** по наблюдению игрока 2026-09-14: каждый продан в одном
экземпляре и исчез из меню. Подсказка напоминает об ожидании пополнения; его время
неизвестно. Для других продавцов увиденный остаток не считается максимальным запасом.
Обновление показывает пометки и в существующем пробеге, не меняя его ожиданий и результатов.

Случайные рецепты из контейнеров, world drops, стартовые рецепты и особые источники
проверяются отдельно через `/ctriage deferred`. Для ручного **Есть** нужно
непосредственное наблюдение происхождения и пояснение. Одного пустого контейнера
недостаточно для **Нет**. Henry Stern требует обучающего gossip в Razorfen Downs,
Pusillin — фактической добычи в Dire Maul East; для них оставлены отдельные инструкции.

## Маршрут и стрелка

Камень привязывается в Шаттрате. Основной путь:

- Шаттрат → портал в Экзодар → острова дренеев → корабль в Auberdine → Тельдрассил / Дарнас.
- Тёмные берега → Ясеневый лес → Everlook → Malygen → Пустоши / караваны → Фералас / Dire Maul East / Feathermoon → Cenarion Hold → Gadgetzan → Ratchet / Razorfen Downs → Терамор.
- Корабль в Менетил → Loch Modan / Badlands → Refuge Pointe → Aerie Peak → Southshore / Ravenholdt → Ironforge / Dun Morogh → Stormwind / Elwynn → Lakeshire → Darkshire → полёт в Rebel Camp → полёт в Westfall → Booty Bay.
- Камень в Шаттрат → Old Man Barlo → Honor Hold → Wildhammer Stronghold → Allerian Stronghold → Telaar → Toshley's Station → Evergrove → Telredor / Cenarion Refuge → Orebor / Sporeggar.

Порядок группирует соседних NPC, использует открытые грифоны и сокращает повторные
переходы между континентами. Личный летающий маунт и маг не нужны. Точное минимальное
время не заявляется: ожидание транспорта, караванов и прохождение инстансов неизвестно.

**TomTom Crazy Arrow** переключается на каждый активный шаг с координатами.
Проверки меню завершаются вручную; перелёты используют штатный тег Guidelime `[F]`.
Связка удаляет только свои точки, восстанавливая прежнюю настройку включения стрелки.
Между континентами стрелка может временно скрыться. У караванов показаны приблизительные
стоянки, у инстансов — входы; это не точные координаты подвижного/внутреннего NPC.

`Deferred Sources` — сезонные точки по условиям, без непрерывного маршрута.
`Skill Breakpoint Checks` — отдельные проверки цвета Spice Bread, Beer Basted Boar Ribs,
Spicy Crawdad и порога Stewed Trout. Они не подменяют статистику источников;
пороги выше TBC-капа 375 этим клиентом не проверяются.

## Сохранения и команды

Результат каждого персонажа: `WTF/Account/<account>/<realm>/<character>/SavedVariables/Guidelime_CookingTriage.lua`,
переменная `CookingTriageDB`. Сохраняются исходные группы/ожидания, версия каталога,
персонаж/сборка/время, результаты и ручные пояснения, последние четыре снимка каждого
меню и последние восемь изменений каждой строки. Старые пробеги не удаляются.

- `/ctriage` — текущий NPC; `/ctriage npc 8137` — конкретный NPC.
- `/ctriage deferred` — отложенные источники.
- `/ctriage report` — текущий отчёт; `/ctriage history` — сохранённые пробеги;
  `/ctriage report 1` — отчёт первого пробега.
- `/ctriage finish` завершает запись; следующий `/ctriage start` создаёт новый пробег.

Сохранённый пробег использует собственную копию каталога даже после обновления аддона.
Новый маршрут может сбросить прогресс шагов Guidelime из-за изменения их числа;
статистика `CookingTriageDB` хранится отдельно. Глобальное распределение каталога до
фильтра по классу: 225 уверенных и 142 сомнительных ожидания, включая отложенные.

## Исходники и проверка

`data/baseline.json` — компактный снимок Cooking-аудита 2026-09-07 и triage 2026-09-08:
116 рецептов, исходные/исправленные/альтернативные источники и спорные места.
`data/current-sources.json` фиксирует дополнительные связи текущего `Recipes.lua`.
`tools/build-catalog.py` применяет явные правила уверенности, фильтрует Horde и
несуществующие TBC-сущности, сверяет контакты квестов и генерирует `Catalog.lua`.
`data/excluded.json` перечисляет исключённые связи; neutral-флаг в ордынской столице
не делает её точкой маршрута Альянса.

Координаты и фракции берутся из установленной Questie TBC, полёты — из Guidelime 5.029.
API trainer tooltip сверены с установленным ARL Scanner и
[Blizzard Trainer UI](https://github.com/Gethe/wow-ui-source/blob/classic_anniversary/Interface/AddOns/Blizzard_TrainerUI/Blizzard_TrainerUI.lua).
Регистрация гайдов: [документация Guidelime](https://github.com/max-ri/Guidelime/wiki/WriteAGuide).
Эти данные задают проверяемые ожидания, не доказывают текущий ассортимент.

Из корня репозитория:

```sh
python3 guides/tools/build-catalog.py
lua guides/tests/cooking-triage.lua
lua guides/tests/verification.lua
luacheck guides/Guidelime_CookingTriage --std lua51 --no-max-line-length
python3 guides/install.py
```

Проверки используют настоящий установленный парсер и custom-code обработчик Guidelime,
базу Questie, а WoW API/TomTom — через mocks. Проверяются покрытие всех NPC/связей,
полёты, контакты квестов, стрелка, обе группы/ожидания, ложные отрицания, запоздалые
события другого NPC, конфликты, отчёты и сохранение пробегов. Это локальная проверка,
не прохождение внутри WoW.

Установщик копирует девять файлов аддона, проверяет байтовое совпадение и сохраняет
прежние файлы в `guides/backups/`. Guidelime, TomTom, ARL и SavedVariables не изменяет.
Другой путь к `Interface/AddOns` можно передать первым аргументом установщика.
